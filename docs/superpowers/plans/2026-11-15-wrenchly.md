# Wrenchly Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a live, no-login web app where a US car owner enters their car, takes Claude-personalized lessons with quizzes, XP and streaks, hits a Stripe test paywall, and unlocks an AI Mechanic photo chat and a 3D Brake Lab.

**Architecture:** One Next.js 15 App Router app on Vercel. Server route handlers own all data access (Supabase Postgres via service-role key) and all third-party calls (NHTSA, Anthropic, Stripe). Guests are identified by an httpOnly `guest_id` cookie. The course catalog lives in code; generated lesson bodies are cached in the DB per car.

**Tech Stack:** Next.js 15, TypeScript, Tailwind, Supabase (`@supabase/supabase-js`), `@anthropic-ai/sdk`, `stripe`, `@react-three/fiber`, `@react-three/drei`, `three`, `zod`, `vitest`.

**Spec:** `docs/superpowers/specs/2026-11-15-wrenchly-design.md`

## Global Constraints

- Deadline 12:00 Nov 15. Code freeze 11:00. Submit by 11:30.
- No login wall anywhere on the core flow. Demo mode labeled "DEMO".
- No hardcoded lesson or chat answers; all lesson/chat content comes from live Claude calls on the user's input.
- Secrets only in Vercel env vars and `.env.local` (gitignored). `.env.example` lists names only.
- `ANTHROPIC_MODEL` default `claude-sonnet-5-5`.
- Price: `$9.99/mo`, `$59.99/yr`. Stripe test mode, inline `price_data`, `mode: "subscription"`.
- Free tier: lesson `<course>-1` of each working course. Everything else premium (other lessons, `part-*` lessons, `/chat`, `/lab`).
- Working courses: `brakes`, `oil-fluids`, `tires-wheels` (3 lessons each). Coming soon: `electrical`, `cooling`, `suspension`, `transmission`, `ev-basics`.
- Lesson keys: `<courseKey>-<n>` (e.g. `brakes-2`). Part keys: `part-rotor`, `part-caliper`, `part-pads`, `part-bracket`, `part-hub`.
- Photo upload: jpeg/png/webp, ≤5 MB, never stored.
- Safety note required on brakes, jacking, airbag, hot-coolant, EV high-voltage content.
- Mobile-responsive layouts.

## Review Focus

1. Invalid/unknown VIN (vPIC `ErrorCode` not `"0"` or empty `Make`): 400 `{error:"VIN not recognized"}`, UI offers year/make/model form. Test in B1.
2. Claude returns malformed lesson JSON or times out: retry once, then 502 `{error}`; nothing cached. Test in B2.
3. Two tabs load the same uncached lesson at once: insert with `onConflict: "car_id,lesson_key"` ignore, then re-select; no 500. Test in B2.
4. Non-premium guest opens premium lesson / `/chat` / `/lab` by direct URL: API 402, page redirects to `/pricing`. Test in A0 (`canAccess`) and B4.
5. Chat upload too big or not an image: 400 before any Claude call. Test in B4.
