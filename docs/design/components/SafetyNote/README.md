# SafetyNote

Required warning block for brakes, jacking, airbags, hot coolant and EV high voltage; the same look marks open recalls.

- Consumer provides: the safety text from the lesson or chat answer. Hide the block when `safety` is null; never render it empty.
- `brake-soft` fill, 1px `brake` border all round, `radius-md`, warning icon in `brake`, eyebrow "SAFETY" in `label` `brake`, text in `body` `ink`.
- Always ends with when to stop and see a pro. No jokes, no exclamation marks.
